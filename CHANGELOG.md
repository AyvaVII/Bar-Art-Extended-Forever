# Changelog

## 1.0

- New command `/rl` as a shortcut for `/reload`.
- Installation path updated for the WoW Forever release: `World of Warcraft\_forever_\Interface\AddOns`.

## 0.1

First release, made for the WoW Forever beta.

- Blizzard-style artwork for action bars: border, dividers, slot backgrounds.
- Works with the default UI (bars 2-8) and with Bartender4 (all bars, including Blizzard bars that Bartender4 does not manage).
- Gryphons on Bartender4 bar 1 with size, distance, height and in-front/behind options.
- Dark Mode with adjustable darkness.
- Profiles: all characters use "Default" until you pick another profile.
- Options page and `/bae` commands.
