# Bar Art Extended

Blizzard-style artwork for your action bars: borders, dividers, slot backgrounds and (with Bartender4) gryphons.
Works with the default UI and with Bartender4. Made for the WoW Forever beta (build 16001).

## Install

1. Download the latest version from [CurseForge](https://www.curseforge.com/wow/addons/bar-art-extended-forever).
2. Unzip the `BarArtExtended` folder to `World of Warcraft\_forever_\Interface\AddOns`.
3. Start WoW and type `/bae`.

## Features

- Border, dividers and slot backgrounds on your action bars
- Default UI: bars 2-8 · Bartender4: all bars
- Gryphons on Bartender4 bar 1 (size, distance, height, in front / behind)
- Dark Mode
- Profiles

## Commands

| Command | What it does |
| --- | --- |
| `/bae` | open the options |
| `/bae on` / `off` | switch the artwork on or off |
| `/bae gryph <x> <y>` | move the gryphons |
| `/bae gryph scale <0.25-1.5>` | gryphon size |
| `/bae gryph front` / `back` | gryphons in front of / behind the bar |
| `/bae margins <l> <r> <t> <b>` / `auto` | border margins by hand / reset |
| `/bae profile [name]` | list or switch profiles |
| `/bae reset` | reset the active profile |
| `/bae debug` | print what the addon found (for bug reports) |
| `/rl` | hortcut for /reload |

## Bug reports

Please open an issue and include the output of `/bae debug` and a screenshot.
